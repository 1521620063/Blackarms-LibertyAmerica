# 浏览器战术版验证记录

当前实现位于 `main`，按原 UE 历史提交 `88bcb3e` 的战术规则制作。测试使用 Node.js 24 与 Windows 本机 Google Chrome 的无头模式。以下结果只代表本地验收，不代表跨设备性能或跨网络环境验收。

## 自动规则与网络测试

`npm test`：**28 项通过，0 失败**。

- 双方所有出生点到三条路线、侧翼与目标的可达路径；路径净空、出生点间视线遮挡、较大移动步长不穿墙。
- 输入净化；射线实际命中、弹药消耗、墙壁遮挡、友方阻挡且无友伤、有限备弹换弹。
- 死亡一次性处理、核心掉落、击杀记录、回合比分不重复增加。
- 核心拾取、移动 / 松键 / 受伤取消、安装、上传、拆除、拆除时上传继续。
- 安装后攻击方阵亡不提前结束上传；未安装超时由防守方获胜。
- 歼灭超时的存活数 / 生命值判定、一次加时及平局。
- 交换攻守保留队伍比分，重置角色和核心。
- 定向 AI 目标场景：绕过碰撞自主到达并安装、上传；防守 AI 主动前往拆除。
- 18 种配置无人比赛全部到达最终比赛结算：2 种模式 × 3 种规模 × 3 档难度。逐帧检查坐标和生命有限、角色未进入障碍物。
- 真实 WebSocket 客户端创建 / 加入房间、房主权限、队伍与装备、统一服务端输入模拟、拒绝客户端位置 / 生命注入、断线 AI 接管、房主转交、空房间回收。

无人比赛使用可重复随机种子，每项配置一场。它证明完整比赛可以结束，不足以证明地图平衡或统计上的长期稳定性。

## 浏览器验收

`npm run build` 构建成功。`npm run test:browser` 启动生产服务并用真实 Chrome 验收：

- 主菜单、模式 / 装备选择、准备阶段、就绪。
- 键盘实际移动、鼠标实际开火与弹药消耗、F1 指令、Tab 记分板。
- 离线暂停确实冻结规则时间；设置调整与刷新后持久化。
- 玩家阵亡后观察队友、最终比赛结算、返回菜单。
- 普通 URL 不暴露调试 API，确认就绪后进入鼠标捕获的战斗状态。
- 两个浏览器客户端创建 / 加入同一房间、选队、开始、就绪、接收服务端状态；一个客户端关闭后由 AI 接管。
- 捕获运行错误；验收期间未记录页面 JavaScript 异常。
- 1440×1000 与 1280×720 截图，人工查看菜单和战斗画面。

规则边界与最终结算通过 `?debug=1` 测试入口设置场景，以免依赖无头浏览器的射击水平；移动、射击、菜单和双客户端房间使用真实输入与网络。完整自然结束的比赛由上面的 18 项规则模拟覆盖。

输出：`artifacts/menu.png`、`combat.png`、`result.png`、`lan.png`、`menu-720p.png` 和 `browser-report.json`。这些是可重新生成的本地文件，不提交 Git。

## 画面升级验收

`npm run test:visual` 使用生产构建与 Chrome，已通过以下检查：

- 六名角色全部加载本地贴图人类士兵模型，每名包含 2 个蒙皮网格和 49 个骨骼关节；角色间骨骼独立。
- Idle / Walk / Run 动画存在；移动改变腿部骨骼，冲刺切换为跑步权重。
- 持枪朝向与角色朝向一致；蹲伏通过腿部 IK 保持脚部高度，未将模型整体沉入地板。
- 三种武器近景、人物正面、枪口火光与弹着效果生成截图，人工检查人物朝向、手臂姿态、材质与地图细节。
- 低 / 中 / 高画质均渲染；静态实体按材质合并至 40 个以下网格批次。
- 连续发射 120 次散射枪效果，验证弹孔最多 80 个、弹道最多 64 条、弹壳最多 40 个；短期效果正常到期并清理。
- 捕获页面异常、控制台错误和 HTTP 错误，验收中均为零。

输出 `artifacts/visual-combat.png`、`visual-soldier.png`、`visual-shot.png`、`visual-pistol.png`、`visual-scatter.png` 与 `visual-report.json`。截图场景通过调试入口布置，作为视觉与动画验证；不替代真实输入和联机验收，也不代表跨硬件帧率基准。

## 生图材质包验收

`npm run test:art` 已通过，检查五类成功生成的素材、共 15 张 1024×1024 WebP 的真实浏览器加载。基础颜色使用 sRGB，法线与粗糙度使用数据色彩空间；对压缩后的四种平铺颜色贴图进行解码，边缘平均差异小于 5 / 255。设备面板按单块贴图使用。

材质包约 6.01 MiB，已查看 3×3 平铺预览和实际游戏截图。验收捕获 JavaScript、控制台及 HTTP 错误，均未记录错误；运行时请求均指向游戏本地服务，没有访问生图接口或外部素材地址。生成过程与原始提示词见 [generated-art.md](generated-art.md) 和 `public/art/manifest.json`。

## 当前限制

- 地图与枪械仍为程序化资产，人物为本地贴图骨骼模型；本次提升了材质、结构、灯光与效果，未达到 UE 写实扫描素材质量。人物共用一种基础模型，通过队伍材质与友方标识区分；倒地使用视觉过渡，没有布娃娃物理。
- 只验收桌面键鼠；没有实现触屏 / 手柄操作。
- AI 覆盖导航、战斗、简单掩体和目标，不等价于原 UE 行为树全部策略；难度 / 地图平衡仍需要真人试玩。
- 局域网以同一台 Node 服务作为比赛权威，不支持 UE 协议互通、互联网匹配、重连恢复、客户端预测和延迟补偿。
- 无头截图环境用于功能验收，没有宣称硬件实测帧率。画质可调，但未实现示例的自动动态分辨率。
- Vite 提示主 JS 超过默认 500 kB 分包阈值（含 Three.js、模型加载器与后处理）；构建成功，压缩传输约 191 kB。人物 GLB 另约 2.06 MiB，通过本地静态服务加载。
