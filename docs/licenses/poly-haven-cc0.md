The original JPEG material maps were converted to 2048 × 2048 WebP for local distribution. The 1K Radiance HDR is distributed unchanged. OpenGL normal maps and roughness maps are treated as linear data; diffuse maps use sRGB. Authored tiling and scene tinting do not imply physically calibrated scale or color.

Exact upstream file URLs, local filenames and processing notes are recorded in `public/art/scanned/manifest.json`. `scripts/prepare-scanned-art.mjs` reproduces the local JPEG-to-WebP conversion. Runtime loads only local packaged assets.
