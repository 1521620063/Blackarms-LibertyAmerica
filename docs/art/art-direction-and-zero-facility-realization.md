## 1. 美术方向定稿（视觉家族）

- 主语言：写实现代军事战术 + 克制科幻能量元素（科幻仅作能量武器/阵营强调，不主导整体）。
- 落地约束：风格必须可由 UE 写实扫描素材库（Quixel Megascan / UE Starter Content）复现，避免卡通、奇幻与高饱和。

### 1.1 色板（职责）
| 角色 | 取值方向 |
|---|---|
| 场景/中性主色 | 低饱和混凝土灰、军绿、沙色、炭黑 |
| 攻击方强调色 | 冷蓝（Cyan/Blue）——臂章、胸甲边缘、能量手枪发光 |
| 防守方强调色 | 暖橙/沙（Orange）——臂章、装甲边缘、应急灯 |
| 场景点缀 | 黄黑警示标识、冷白荧光灯、暖橙应急灯 |

### 1.2 材质语言
- 主体材质：磨砂聚合物、拉丝金属、旧化刮痕、战术织物尼龙、混凝土、金属地板格栅。
- 表面处理：中度旧化、非全新；接触磨损集中在掩体边缘、地面走线、门框。

### 1.3 光影与画面
- 主光：冷硬方向光（顶部天窗 / 侧面窗户引入）。
- 补光：冷白荧光 + 暖橙应急灯的色温对比；轻微体积光；地面投格栅阴影。
- 引擎侧：Lumen 动态全局光照，不烘焙。

### 1.4 阵营识别（角色）
- 攻击方：蓝、机动轻装、能量手枪。
- 防守方：橙、重甲、脉冲步枪。

## 3. 关键资产清单与落地优先级

按「最大视觉收益 / 最低风险」排序：

1. **地面与墙体**（最大视觉面积，Quixel 拖拽即用，收益最高）
2. **掩体与中央高台**（结构件，低模 + 扫描贴图）
3. **管道与警示贴花**（点缀，快）
4. **布光与后期**（Lumen + 色彩分级 + 胶片颗粒）
5. **角色与武器**（需建模/生成，最后做）

## 4. Lumen 布光与后期
- 光照：默认 Lumen（动态全局光照），无需烘焙。
- 色温对比：冷白荧光主光（约 5500K）+ 暖橙应急灯（约 2500K）。
- 后期：轻微降对比、降低饱和、加轻度胶片颗粒。
